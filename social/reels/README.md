# Netherhouse Mews — 12 Reel Campaign

This campaign uses the **existing Netherhouse Mews repository media and project data** to produce twelve vertical social reels.

## Format
- 1080 × 1920
- 9:16 vertical
- H.264 MP4
- 12 seconds each
- FOX Digital Land branding
- Fine & Country sales branding
- Real planning, house-type and contact information from the live project code

## Reel sequence
1. Project Story
2. Redevelopment Story
3. Masterplan
4. The Hillside — Plots 1 & 2
5. Plot 1
6. Plot 2
7. The Meadow — Plot 3
8. The Ridge — Plot 4
9. Planning — AVA/2025/0519
10. Biodiversity & Landscape
11. Location — Turnditch
12. Fine & Country / Anthony Taylor

## Source media
The renderer uses the repository's existing:
- hero and site films
- house-type films
- aerial CGI
- plot CGI
- masterplan
- FOX logo
- Fine & Country logo

## Render locally
```bash
python3 social/reels/render_reels.py
```

GitHub Actions also renders the full set and uploads a ZIP artifact automatically.
